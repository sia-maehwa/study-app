# 영어 과목 모듈

현재 상태: **실전 평가 사용 가능 · 개념 학습 콘텐츠는 미등록**

## 등록된 평가

- 2026학년도 대학수학능력시험 영어 홀수형 1회
- 45문항 · 70분 · 총 100점
- 듣기 17문항, 읽기 28문항
- 평가원 공식 정답표의 정답과 배점을 등록하고 공통 평가 엔진으로 검증합니다.
- 영어 절대평가 등급 기준(90/80/70/60/50/40/30/20점)을 적용합니다.

## 앱 내 원문과 듣기

- 한국교육과정평가원 문제지 PDF에서 홀수형 1~8쪽을 이미지 자산으로 준비합니다.
- 각 문항 화면에는 해당 문항이 포함된 원문 페이지가 표시됩니다. 이미지를 누르면 원본 크기로 열립니다.
- 듣기 1~17번은 EBSi 배포 MP3를 앱 자산으로 포함합니다. 문항을 이동해도 재생 위치와 재생 상태를 이어가도록 처리했습니다.
- 서비스 워커가 원문 페이지 8장과 MP3를 설치 캐시에 저장하므로, 한 번 설치 자산이 내려오면 오프라인에서도 원문과 음원을 이용할 수 있습니다.
- 공식 평가원 문제지와 정답표, EBSi 음원 배포 주소를 출처 메타데이터로 보존합니다.

## 자동 자산 준비

`tools/prepare-english-csat-assets.sh`가 GitHub Actions에서 평가원 PDF와 EBSi MP3를 가져와 페이지 이미지와 음원 파일을 생성합니다. 빌드 검증은 8개 JPEG의 무결성, MP3 파일 헤더, 문항별 페이지 연결, 정답·배점·문항 수를 검사합니다.

## 이후 추가할 항목

- 짝수형 및 2026학년도 6월·9월 모의평가
- 듣기 문항별 구간 바로가기
- 어휘·독해 단원, 개념 설명, 자체 제작 학습 문항

현재 영어 과목은 실전 평가 답안 입력·채점 기능을 제공하며, 사회·문화의 개념 학습 화면과 저장 키를 공유하지 않습니다.
