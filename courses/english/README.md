# 영어 과목 모듈

현재 상태: **실전 평가 사용 가능 · 개념 학습 콘텐츠는 미등록**

## 등록된 평가

- 2026학년도 대학수학능력시험 영어 홀수형 1회
- 45문항 · 70분 · 총 100점
- 듣기 17문항, 읽기 28문항
- 한국교육과정평가원 공식 정답표를 기준으로 정답과 배점을 검증했습니다.
- 영어 절대평가 등급 기준(90/80/70/60/50/40/30/20점)을 적용합니다.

## 원문 및 음원 제한

문항 본문·지문·도표와 선택지 원문은 저장소에 복제하지 않습니다. 시험 응시 중 제공되는 공식 PDF 링크를 열어 원문을 확인하고, 이 앱에서 답안을 입력·채점하는 방식입니다. 따라서 원문 PDF 열람에는 인터넷 연결이 필요합니다.

듣기 1~17번의 재생 음원은 앱에 포함되어 있지 않습니다. 해당 문항은 별도 음원을 준비해 재생해야 합니다. 음원 제공이 검증되기 전까지 앱이 듣기 파일을 제공한다고 표시하지 않습니다.

## 이후 추가할 항목

- 검증된 듣기 음원 연결과 재생 제어
- 원문 PDF를 앱 안에서 안정적으로 열람하는 방법 또는 사용 권한이 확인된 오프라인 자료
- 어휘·독해 단원, 개념 설명, 자체 제작 학습 문항
- 추가 학년도 수능·모의평가 및 짝수형 데이터

현재 영어 과목은 실전 평가 답안지 기능만 제공하며, 사회·문화 개념 학습 화면을 재사용하지 않습니다.
