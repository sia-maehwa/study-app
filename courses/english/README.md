# 영어 과목 모듈

현재 상태: **준비 중**

이 과목은 과목 레지스트리에 planned 상태로 등록되어 있습니다. 실제 지문·문항·정답·해설과 출처 검증이 완료되기 전까지 학습 선택 및 평가 목록에는 노출하지 않습니다.

아직 문항 데이터는 등록하지 않았습니다. 임의로 만든 지문이나 정답을 실제 학습 콘텐츠처럼 제공하지 않습니다.

## 콘텐츠 등록 전 확인 사항

- 교육과정 및 평가 범위 확정
- 지문 원문과 사용 권한·출처 확인
- 문항 유형, 정답, 해설 검수
- 듣기 자료가 포함될 경우 오디오 파일과 재생 동작 검증
- AssessmentEngine 스키마 검증 및 과목별 빌드 테스트

콘텐츠 준비가 끝나면 content.js와 assessments.js를 추가하고, 레지스트리의 상태를 available로 전환해야 합니다.
