# 학습노트

사회·문화 단원별 개념 문제, 오답 노트, 실전 모의고사로 구성된 로컬 실행 웹앱입니다.

## ZIP으로 받아 로컬 실행

1. GitHub 저장소에서 **Code → Download ZIP**을 선택합니다.
2. 태블릿에서 ZIP을 압축 해제합니다.
3. 압축 해제한 폴더의 **`index.html`**을 Chrome으로 엽니다.

배포용 `index.html`에는 CSS, JavaScript, 2022~2026학년도 평가원 기출 이미지 300장이 포함되어 있습니다. Termux, Python 서버, 설치, 인터넷 연결이 필요하지 않습니다. `app-source.html`, `css/`, `js/`, `assets/`는 원본 소스입니다.

## Chrome 앱 설치

배포 주소(`https://sia-maehwa.github.io/study-app/`)는 PWA 설치를 지원합니다.

1. Chrome에서 배포 주소를 엽니다.
2. Chrome 오른쪽 위 메뉴(⋮)에서 **앱 설치**를 선택합니다. 기기나 Chrome 버전에 따라 **홈 화면에 추가**로 표시될 수 있습니다.
3. 설치가 끝나면 홈 화면의 **학습노트** 아이콘으로 실행할 수 있습니다.

첫 접속 때 앱 기본 파일이 캐시됩니다. 이후 다시 방문한 페이지와 이미 열어 본 시험 이미지 일부는 오프라인에서도 사용할 수 있습니다. 아직 한 번도 불러오지 않은 시험 이미지는 첫 온라인 접속이 필요합니다.

학습 기록과 필기는 기존과 동일하게 브라우저 로컬 저장소에 보관됩니다.

## 과목 선택

첫 실행 시 과목 선택 화면이 표시됩니다. 사회·문화는 단원별 개념 학습과 기출 평가를 제공하며, 영어는 2026학년도 수능 홀수형 45문항의 답안 입력·채점을 제공합니다. 영어는 현재 문항이 포함된 평가원 원문 페이지 이미지 8쪽과 듣기 1~17번 통합 음원을 앱 자산으로 포함합니다. 듣기 재생 위치는 문항을 이동해도 이어집니다. 원문 페이지 이미지는 눌러 원본 크기로 볼 수 있으며, 앱 설치 후에는 오프라인에서도 문제와 음원을 이용할 수 있습니다. 선택한 과목은 브라우저 로컬 저장소에 기억됩니다.

## 스타일러스 필기와 호버

- 문제 화면 전체가 필기 영역입니다. 별도 필기 상자를 늘리는 방식이 아닙니다.
- 스타일러스가 화면에 닿지 않고 버튼·선택지 위를 지나갈 때 팝업처럼 확대되는 호버 효과를 표시합니다.
- 스타일러스는 필기하고, 손가락은 획으로 저장하지 않고 화면을 드래그·스크롤합니다.
- 펜 색상 6가지, 지우개, 필기 끄기, 실행 취소, 다시 실행, 문항별 전체 지우기를 지원합니다.
- 필기는 퀴즈 문제 ID별, 모의고사 시험·문항별로 브라우저 저장소에 구분해 저장됩니다.
- 스타일러스 호버 단계에서 필기 영역의 브라우저 스크롤 제스처를 미리 잠그고, 펜이 영역을 벗어나면 손가락 스크롤을 복구합니다. 브라우저가 스타일러스를 `PointerEvent.pointerType = "pen"`으로 전달해야 펜과 손가락을 안전하게 구분할 수 있습니다. `touch`로만 전달되는 범용 정전식 터치펜은 손가락과 구분할 수 없습니다.

## 갤러리 이미지 노출 방지

`assets/.nomedia` 파일이 해당 폴더와 하위 폴더의 이미지가 Android 갤러리에 등록되지 않도록 합니다. 이미 미디어 목록에 등록된 파일은 기기에서 갤러리 캐시를 갱신한 뒤 사라질 수 있습니다. `.nomedia`는 파일 관리자에서는 이미지를 숨기거나 암호화하지 않습니다.

## 과목 콘텐츠 구조

- `js/course-registry.js`: 과목별 학습 단계, 학문 분야, 교육과정, 콘텐츠·평가 데이터 연결 키, 평가 프로필을 관리합니다.
- `courses/<course-id>/content.js`: 해당 과목의 단원, 문제 은행, 개념 자료를 보관합니다.
- `courses/<course-id>/assessments.js`: 해당 과목의 기출·연습 시험과 평가별 데이터(등급컷 등)를 보관합니다. 영어 원문 페이지 이미지와 듣기 음원은 GitHub Actions가 한국교육과정평가원·EBSi 배포 파일에서 준비해 `assets/`에 포함하고, 서비스 워커가 오프라인 캐시로 관리합니다.
- `js/assessment-engine.js`: 과목과 분리된 공통 문항 정규화·검증·채점 엔진입니다. 단일 선택, 복수 선택, 단답형, 수치형, 서술형, 코드 응답 유형을 구분합니다.
- `js/data.js`, `js/exams.js`, `js/predict.js`: 현재 사회·문화 화면과 게임·시험 UI의 기존 데이터 참조를 유지하는 호환 어댑터입니다. 과목 콘텐츠 원본은 `courses/` 아래에 둡니다.
- 콘텐츠와 평가 데이터가 실제로 연결되고 빌드 검증된 과목만 과목 선택 화면에 표시합니다.

새 과목을 추가할 때는 과목 전용 콘텐츠·평가 모듈을 준비하고, 과목 레지스트리에 연결한 다음 빌드 검증을 통과시켜야 합니다. 공통 엔진은 자동 채점 가능한 응답과 수동 채점이 필요한 응답을 구분합니다. 복수 선택은 정답 집합 일치, 단답형은 정규화된 허용 답안, 수치형은 허용 오차를 사용하며, 서술형·코드는 루브릭 또는 테스트 기준을 통해 별도 채점하도록 설계합니다.

## 원본 수정과 실행본 생성

`courses/`, `js/`, `css/`, `assets/`의 모듈형 원본을 수정합니다. `tools/build-offline.js`가 실행용 HTML과 런타임 자산 구성을 검증합니다. GitHub Actions가 `main` 변경 시 최상위 `index.html`을 자동 갱신합니다. 이후 GitHub ZIP을 다시 받으면 갱신된 실행본을 사용할 수 있습니다.

학습 기록과 필기는 브라우저 로컬 저장소에 보관되며 기기 간 자동 동기화는 제공하지 않습니다.
